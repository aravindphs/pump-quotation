# N Square Energies — Solar Agriculture Pump Quotation Generator

A fast, simple, professional quotation generator for **N Square Energies**
*(a unit of ZetaCorp Solutions Private Limited)*, Coimbatore, Tamil Nadu.

Built so a salesperson can create and send a customer-ready Solar Agriculture
Pump quotation in **under two minutes** — no engineering BOQ, no accounting
system, no subsidy handling. Just Customer → Pump → Panel → Drive → Price →
Quotation.

**Live app:** open `index.html` in any browser, or see it hosted at
`https://claude.ai/artifact/T5sZmR9DyCQKbyncWkEEPK`.

## Features

- **Dashboard** — quotation counts (total / this month / accepted / pending), quick links
- **New quotation** — Customer, Pump, Solar Panel (auto-calculates total kW), Drive,
  Project (structure / installation / transportation), Price — with a live A4 preview
- **Automatic GST** — internally split 70% goods @ 5% GST / 30% services @ 18% GST
  (configurable). The customer-facing quotation only ever shows **Price → GST → Total**
- **Payment terms** — auto-split 80% advance / 20% balance after installation
- **Quotation numbering** — auto-generated (`NSE/SP/2026/0001`), configurable prefix
  and starting number, 15-day default validity
- **Actions** — Save, Print (A4), Download PDF, Share on WhatsApp (pre-filled message)
- **Saved quotations** — search by number / customer name / mobile, edit, duplicate,
  delete, update status (Draft / Sent / Accepted / Rejected)
- **Settings** — company details & logo, quotation numbering, warranty defaults,
  terms & conditions, GST configuration
- Fully responsive (desktop / tablet / mobile), data stored in the browser
  (LocalStorage) — no backend required

## Tech stack

- React 18 + TypeScript, bundled with [esbuild](https://esbuild.github.io/)
- Plain CSS (no framework) for a lightweight, self-contained build
- [html2canvas](https://html2canvas.hertzen.com/) + [jsPDF](https://github.com/parallax/jsPDF) for one-page A4 PDF export
- Ships as a **single self-contained `index.html`** — no build step required to use it,
  just open the file

## Project structure

```
.
├── index.html        # built, self-contained app (open this to use it)
├── bundle.js          # built JS bundle (generated by build.js, committed for convenience)
├── build.js           # bundles src/ and regenerates index.html
├── package.json
└── src/
    ├── app.tsx         # all application logic and UI (React + TypeScript)
    ├── style.css       # styles, including the printable A4 quotation layout
    └── logo.ts         # default company logo (base64 data URI)
```

## Developing

```bash
npm install
npm run build     # regenerates bundle.js and index.html from src/
```

Then open `index.html` in a browser. There's no dev server — edit `src/`,
re-run `npm run build`, and reload the page.

## Configuration

All company-specific settings — name, address, phone, GSTIN, logo, quotation
prefix/numbering, default validity, warranty text, terms & conditions, and the
GST split/rates — are editable from the in-app **Settings** page and persist
in the browser. Nothing needs to be hard-coded or rebuilt to change them.
